# M1-D3 OPC UA zwischen Anlage und Maschinen – Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Auf dem Server spricht die Anlage mit ihren Maschinen nur noch über OPC UA (Eclipse Milo): die Simulation sitzt hinter einem OPC-UA-Server, ein Gateway ruft sie je Schritt auf, und Server, Arbeitsspeicher und Browser liefern weiterhin bei gleichem Seed dieselbe Ereignisfolge. Verbindungsverlust macht die Maschinen `UNKNOWN`, nach der Rückkehr gilt wieder ihr echter Zustand.

**Architecture:** Neuer Kern-Port `MachineGateway` in `platform/plant`: `Plant` ruft die Maschinen nur noch über ihn auf. Im Speicher (`LocalMachines`) und auf dem Server (`OpcUaMachines`) sammeln die Maschinen ihre Rückmeldungen in einer `FeedbackOutbox`; das Gateway gibt sie nach dem auslösenden Aufruf an SmartFactory weiter, auf dem Server als Ergebnis des OPC-UA-Methodenaufrufs. Dadurch ist der Zeitpunkt jeder Rückmeldung in beiden Laufzeiten gleich. Der `MachineServer` (Milo, nur `127.0.0.1`) zeigt je Maschine ihre Werte als Variablen und bietet die Befehle als Methoden an, die nur das Gateway aufrufen darf.

**Tech Stack:** Java 25, Spring Boot 4.1.2, Eclipse Milo 1.1.8 (`milo-sdk-server`, `milo-sdk-client`), PostgreSQL 18 (embedded), TeaVM 0.16.0, JUnit 5, AssertJ.

**Spec:** `docs/superpowers/specs/2026-11-10-nexus-industrial-os-design.md` (Revision 2), Abschnitte 2a, 5, 8, 9, 11, 16, 17. Dieser Plan hebt die Spec auf Revision 3 (Task 6, letzter Schritt). Voraussetzung: M1-D2 ist gemergt (`e0d2219`).

**Form:** wie M1-D2, aber mit vollständigem Code für alles, was neu ist (Draht-Format, Server, Gateway). Die Milo-Aufrufe in diesem Plan sind in einem Wegwerf-Versuch gegen Milo 1.1.8 unter dem Spring-Boot-Parent (Netty 4.2.19) geprüft: typisierte Argumente, Arrays, `null`-Strings, Benutzerprüfung im Methoden-Handler, automatisches Wiederverbinden nach Server-Neustart (rund 3 s), `RuntimeException` im Handler wird zu `Bad_InternalError`.

## Entscheidungen dieses Plans

- **Rückmeldungen über eine Outbox, in beiden Laufzeiten.** Bisher rief die Simulation SmartFactory mitten im Schritt auf. Jetzt sammelt `FeedbackOutbox` die Rückmeldungen, und das Gateway gibt sie nach dem Aufruf (Schritt oder Befehl) in Reihenfolge weiter. Über OPC UA geht es nicht anders, und der Speicher macht es gleich, damit Server und Browser dieselbe Ereignisfolge behalten. Die Ereignisfolge im Speicher ändert sich dadurch einmalig. Kein Test vergleicht gegen eine gespeicherte Folge; alle Vergleiche laufen Laufzeit gegen Laufzeit.
- **Synchrone Methodenaufrufe statt Subscriptions im Gateway.** Benachrichtigungen einer Subscription kommen auf Milo-Threads zu beliebigen Zeitpunkten und würden die feste Schrittfolge (Spec 11) brechen. Der Server bietet Subscriptions trotzdem an (Milo `SubscriptionModel`), für fremde OPC-UA-Clients wie UaExpert. Abweichung von Spec 9, Revision 3 hält sie fest.
- **Das Gateway gehört zur Anlage, nicht zu FlowPilot.** Spec 5 nennt einen OPC-UA-Client „in FlowPilot". FlowPilot hat mit Maschinen nichts zu tun; die Rückmeldungen gehen an SmartFactory. Revision 3 korrigiert das.
- **Neuer Maschinenzustand `UNKNOWN`.** Nur das Gateway setzt ihn, bei Verbindungsverlust. SmartFactory behandelt ihn wie eine gestörte Maschine: nicht verfügbar, fällt aus der Planung, bekommt weder Aufträge noch Material.
- **Jeder Aufruf hat eine Aufruf-ID.** Der Server merkt sich die letzten 16 Antworten. Geht eine Antwort verloren, schickt das Gateway denselben Aufruf noch einmal, sofort oder nach der Wiederverbindung, und der Server führt ihn nur einmal aus.
- **Methoden nur für das Gateway.** Es meldet sich mit einem Passwort an, das der Server bei jedem Start neu erzeugt. Jeder andere Client darf lesen und abonnieren, aber keine Methode aufrufen: ein Befehl an SmartFactory vorbei brächte beide aus dem Tritt. Endpunkt nur auf `127.0.0.1`, `SecurityPolicy.None` (lokaler Betrieb, Spec 16).
- **Ausnahmen kommen als dieselbe Ausnahme an.** `DomainException` (mit Art und Text) und `IllegalTransitionException` werden über den Draht übertragen und im Gateway gleich neu erzeugt, damit Meldungen und REST-Fehler gleich bleiben. Andere Ausnahmen (Programmfehler) kommen als `IllegalStateException` mit dem Klassennamen an.
- **`machine.material_request` bleibt ungenutzt.** Die Simulation fordert kein Material an; SmartFactory fordert es bei der Freigabe selbst an. Revision 3 hält das fest.

## Global Constraints

- Alles aus `2026-11-10-m1a2-portabler-kern.md`, Abschnitt Global Constraints, gilt weiter.
- `platform/plant` bleibt Kern: kein Milo, keine Threads, keine Systemzeit, keine Reflection. `FeedbackOutbox`, `LocalMachines`, `PlantMachines` und `MachineWire` liegen dort; was der Browser erreicht, übersetzt TeaVM.
- Milo nur in `platform/app`, Version `1.1.8`: `org.eclipse.milo:milo-sdk-server` und `org.eclipse.milo:milo-sdk-client`.
- Lock-Regel: Das Gateway wird nur unter dem Plattform-Lock (Monitor des `EventBus`) aufgerufen. Die Methoden-Handler des Servers nehmen nie den Plattform-Lock, nur den eigenen Lock des `MachineServer`. Milo-Threads setzen im Gateway nur ein `volatile`-Flag.
- Port: `nexus.opcua.port`, Standard `4840`, in Tests `0` (freier Port). Endpunkt `opc.tcp://127.0.0.1:<port>/nexus`.
- Texte für Benutzer auf Deutsch, Code und Kommentare auf Englisch.
- Commits enden mit `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Nicht pushen.

## Review Focus

1. **Antwort geht verloren.** Ein Aufruf läuft auf dem Server, aber die Antwort erreicht das Gateway nicht (Timeout, Verbindungsabbruch). Erwartet: der Aufruf wirkt genau einmal, seine Rückmeldungen kommen genau einmal bei SmartFactory an. Test in Task 6 (`aCallWhoseAnswerIsLostRunsExactlyOnce`).
2. **Server weg, Schleife läuft.** Ohne Server darf kein Schritt auf eine Zeitüberschreitung warten, sonst hielte jeder Schritt den Plattform-Lock bis zu 2 s und REST stünde. Erwartet: 100 Schritte ohne Server in unter 2 s. Test in Task 6 (`stepsDoNotWaitForAServerThatIsGone`).

```java
package io.nexus.plant.machines;

import io.nexus.contracts.port.MachineControl;
import io.nexus.sim.SimRules;
import io.nexus.sim.Simulation;
import java.util.List;

/**
 * The plant's way to its machines (Spec 2a, port MachineGateway): in memory a direct call, on the server OPC UA.
 * Either way every report a call causes has reached the feedback target (SmartFactory) before the call returns, in
 * the order the machines made them, and an exception the machines threw is rethrown after those reports. All calls
 * come from the plant, one at a time, under the platform lock.
 */
public interface MachineGateway extends MachineControl {
  /** New machines for this seed: idle, cold, unworn, random stream new SeededRandom(seed).fork("sim"). */
  void reset(long seed);

  void step(long dtMs);

  void setRules(SimRules rules);

  void configure(String machineId, int overridePercent, boolean coolant);

  /** The machines in id order. */
  List<Simulation.MachineView> views();

  List<Simulation.ConveyorView> conveyors();
}
```

```java
package io.nexus.plant.machines;

import io.nexus.contracts.port.MachineFeedback;
import io.nexus.contracts.state.MachineStatus;
import java.util.ArrayList;
import java.util.List;

/**
 * Collects what the machines report instead of passing it on at once. The gateway hands the reports on after the
 * call that caused them (in memory) or sends them back as the call's answer (OPC UA), so both runtimes deliver the
 * same reports in the same order at the same moment.
 */
public final class FeedbackOutbox implements MachineFeedback {
  public sealed interface Item permits StatusChanged, FaultRaised, JobFinished, ConveyorDelivered {
    String machineId();

    void deliverTo(MachineFeedback target);
  }

  public record StatusChanged(String machineId, MachineStatus from, MachineStatus to) implements Item {
    @Override
    public void deliverTo(MachineFeedback target) {
      target.statusChanged(machineId, from, to);
    }
  }

  public record FaultRaised(String machineId, String faultTypeId, String label, boolean scrappedWorkpiece)
      implements Item {
    @Override
    public void deliverTo(MachineFeedback target) {
      target.faultRaised(machineId, faultTypeId, label, scrappedWorkpiece);
    }
  }

  public record JobFinished(String machineId, String orderId, int stepSeq, int good, int scrap) implements Item {
    @Override
    public void deliverTo(MachineFeedback target) {
      target.jobFinished(machineId, orderId, stepSeq, good, scrap);
    }
  }

  public record ConveyorDelivered(String machineId, String orderId, int stepSeq, int quantity) implements Item {
    @Override
    public void deliverTo(MachineFeedback target) {
      target.conveyorDelivered(machineId, orderId, stepSeq, quantity);
    }
  }

  private final List<Item> items = new ArrayList<>();

  @Override
  public void statusChanged(String machineId, MachineStatus from, MachineStatus to) {
    items.add(new StatusChanged(machineId, from, to));
  }

  @Override
  public void faultRaised(String machineId, String faultTypeId, String label, boolean scrappedWorkpiece) {
    items.add(new FaultRaised(machineId, faultTypeId, label, scrappedWorkpiece));
  }

  @Override
  public void jobFinished(String machineId, String orderId, int stepSeq, int good, int scrap) {
    items.add(new JobFinished(machineId, orderId, stepSeq, good, scrap));
  }

  @Override
  public void conveyorDelivered(String machineId, String orderId, int stepSeq, int quantity) {
    items.add(new ConveyorDelivered(machineId, orderId, stepSeq, quantity));
  }

  /** Everything reported since the last drain, oldest first; the outbox is empty afterwards. */
  public List<Item> drain() {
    List<Item> out = new ArrayList<>(items);
    items.clear();
    return out;
  }
}
```

```java
package io.nexus.plant.machines;

import io.nexus.contracts.port.MachineFeedback;
import io.nexus.contracts.sim.SeededRandom;
import io.nexus.sim.Simulation;
import io.nexus.smartfactory.master.SmartFactoryMasterData;
import java.util.ArrayList;
import java.util.List;

/** The machines and conveyors of this plant, from SmartFactory's master data. Used in memory and by the OPC UA server. */
public final class PlantMachines {
  /** Drop and take positions on the collecting conveyor CV-03, from FactoryTwin/src/sim/initialState.ts. */
  private static final double CV03_LENGTH_M = 27;
  private static final double CV03_SPEED_MPS = 0.6;

  private PlantMachines() {}

  /** New machines reporting to feedback, with the random stream new SeededRandom(seed).fork("sim"). */
  public static Simulation newSimulation(long seed, MachineFeedback feedback) {
    List<Simulation.MachineSpec> specs = new ArrayList<>();
    for (SmartFactoryMasterData.Machine m : SmartFactoryMasterData.machines()) {
      specs.add(new Simulation.MachineSpec(m.id(), m.kind()));
    }
    List<Simulation.ConveyorLink> links = new ArrayList<>();
    for (SmartFactoryMasterData.ConveyorLink l : SmartFactoryMasterData.conveyorLinks()) {
      links.add(new Simulation.ConveyorLink(l.fromMachineId(), l.conveyorId(), l.toMachineId(), dropAt(l.fromMachineId()),
          CV03_LENGTH_M, CV03_SPEED_MPS));
    }
    return new Simulation(specs, links, new SeededRandom(seed).fork("sim"), feedback);
  }

  /** Machine ids in id order, as the simulation keeps them. */
  public static List<String> machineIds() {
    List<String> ids = new ArrayList<>();
    for (SmartFactoryMasterData.Machine m : SmartFactoryMasterData.machines()) ids.add(m.id());
    ids.sort(String::compareTo);
    return ids;
  }

  /** Conveyor ids in id order. */
  public static List<String> conveyorIds() {
    List<String> ids = new ArrayList<>();
    for (SmartFactoryMasterData.ConveyorLink l : SmartFactoryMasterData.conveyorLinks()) {
      if (!ids.contains(l.conveyorId())) ids.add(l.conveyorId());
    }
    ids.sort(String::compareTo);
    return ids;
  }

  private static double dropAt(String machineId) {
    return switch (machineId) {
      case "ROB-01" -> 6.7;
      case "ROB-02" -> 15.7;
      default -> throw new IllegalStateException("Keine Ablageposition auf CV-03 für " + machineId);
    };
  }
}
```

```java
package io.nexus.plant.machines;

import io.nexus.contracts.port.MachineFeedback;
import io.nexus.sim.SimRules;
import io.nexus.sim.Simulation;
import java.util.List;

/**
 * The machines in memory: the browser runtime and the core tests. Each call runs on the simulation, then the
 * reports it caused are handed to the target in order. A report may lead to a new command (SmartFactory starts the
 * next batch); that command's reports are handed on before the rest of the outer ones, as OPC UA does it too.
 */
public final class LocalMachines implements MachineGateway {
  private final MachineFeedback target;
  private final FeedbackOutbox outbox = new FeedbackOutbox();
  private Simulation simulation;

  public LocalMachines(MachineFeedback target) {
    this.target = target;
  }

  private void call(Runnable command) {
    try {
      command.run();
    } finally {
      for (FeedbackOutbox.Item item : outbox.drain()) item.deliverTo(target);
    }
  }

  @Override public void reset(long seed) { simulation = PlantMachines.newSimulation(seed, outbox); }

  @Override public void step(long dtMs) { call(() -> simulation.step(dtMs)); }

  @Override public void setRules(SimRules rules) { simulation.setRules(rules); }

  @Override public void configure(String machineId, int overridePercent, boolean coolant) {
    call(() -> simulation.configure(machineId, overridePercent, coolant));
  }

  @Override public List<Simulation.MachineView> views() { return simulation.machines(); }

  @Override public List<Simulation.ConveyorView> conveyors() { return simulation.conveyors(); }

  @Override public void start(String machineId) { call(() -> simulation.start(machineId)); }

  @Override public void stop(String machineId) { call(() -> simulation.stop(machineId)); }

  @Override public void injectFault(String machineId, String faultTypeId) {
    call(() -> simulation.injectFault(machineId, faultTypeId));
  }

  @Override public void repair(String machineId) { call(() -> simulation.repair(machineId)); }

  @Override public void maintain(String machineId) { call(() -> simulation.maintain(machineId)); }

  @Override public void startJob(MachineJob job) { call(() -> simulation.startJob(job)); }
}
```

```java
package io.nexus.plant.machines;

import io.nexus.contracts.DomainException;
import io.nexus.contracts.json.JsonReader;
import io.nexus.contracts.json.JsonWriter;
import io.nexus.contracts.state.IllegalTransitionException;
import io.nexus.contracts.state.MachineStatus;
import java.util.ArrayList;
import java.util.List;
import java.util.Map;

/**
 * The text form of machine reports and errors in an OPC UA answer. Only strings, whole numbers and booleans, so
 * both ends see exactly the same values. Reports that make no sense are left out and named (Spec 9: discarded and
 * logged); the caller decides how to log them.
 */
public final class MachineWire {
  public record Parsed(List<FeedbackOutbox.Item> items, List<String> rejected) {}

  private MachineWire() {}

  public static String items(List<FeedbackOutbox.Item> items) {
    var w = new JsonWriter().beginArray();
    for (FeedbackOutbox.Item item : items) {
      w.beginObject();
      switch (item) {
        case FeedbackOutbox.StatusChanged s -> w.name("t").value("status").name("m").value(s.machineId())
            .name("from").value(s.from().name()).name("to").value(s.to().name());
        case FeedbackOutbox.FaultRaised f -> w.name("t").value("fault").name("m").value(f.machineId())
            .name("fault").value(f.faultTypeId()).name("label").value(f.label())
            .name("scrapped").value(f.scrappedWorkpiece());
        case FeedbackOutbox.JobFinished j -> w.name("t").value("finished").name("m").value(j.machineId())
            .name("order").value(j.orderId()).name("step").value(j.stepSeq())
            .name("good").value(j.good()).name("scrap").value(j.scrap());
        case FeedbackOutbox.ConveyorDelivered c -> w.name("t").value("conveyor").name("m").value(c.machineId())
            .name("order").value(c.orderId()).name("step").value(c.stepSeq()).name("qty").value(c.quantity());
      }
      w.endObject();
    }
    return w.endArray().toString();
  }

  public static Parsed parseItems(String json, List<String> machineIds) {
    List<FeedbackOutbox.Item> items = new ArrayList<>();
    List<String> rejected = new ArrayList<>();
    Object root;
    try {
      root = JsonReader.parse(json);
    } catch (RuntimeException unreadable) {
      rejected.add("Meldungen unlesbar: " + unreadable.getMessage());
      return new Parsed(items, rejected);
    }
    if (!(root instanceof List<?> list)) {
      rejected.add("Meldungen sind keine Liste");
      return new Parsed(items, rejected);
    }
    for (Object o : list) {
      try {
        items.add(item(o, machineIds));
      } catch (IllegalArgumentException wrong) {
        rejected.add(wrong.getMessage());
      }
    }
    return new Parsed(items, rejected);
  }

  private static FeedbackOutbox.Item item(Object o, List<String> machineIds) {
    if (!(o instanceof Map<?, ?> m)) throw new IllegalArgumentException("Meldung ist kein Objekt");
    String machine = text(m, "m");
    if (!machineIds.contains(machine)) throw new IllegalArgumentException("unbekannte Maschine " + shorten(machine));
    String type = text(m, "t");
    return switch (type) {
      case "status" -> new FeedbackOutbox.StatusChanged(machine, reported(m, "from"), reported(m, "to"));
      case "fault" -> new FeedbackOutbox.FaultRaised(machine, text(m, "fault"), text(m, "label"), flag(m, "scrapped"));
      case "finished" -> new FeedbackOutbox.JobFinished(machine, text(m, "order"), count(m, "step"), count(m, "good"),
          count(m, "scrap"));
      case "conveyor" -> new FeedbackOutbox.ConveyorDelivered(machine, text(m, "order"), count(m, "step"),
          count(m, "qty"));
      default -> throw new IllegalArgumentException("unbekannte Meldungsart " + shorten(type));
    };
  }

  public static String error(RuntimeException e) {
    var w = new JsonWriter().beginObject();
    if (e instanceof DomainException d) {
      w.name("kind").value("domain").name("domainKind").value(d.kind().name()).name("message").value(d.getMessage());
    } else if (e instanceof IllegalTransitionException t && t.from() != null && t.to() != null) {
      w.name("kind").value("transition").name("entity").value(t.entityId())
          .name("from").value(t.from().name()).name("to").value(t.to().name());
    } else {
      String type = e.getClass().getName();
      w.name("kind").value("other").name("type").value(type.substring(type.lastIndexOf('.') + 1));
    }
    return w.endObject().toString();
  }

  public static RuntimeException exception(String json) {
    try {
      if (!(JsonReader.parse(json) instanceof Map<?, ?> m)) throw new IllegalArgumentException("kein Objekt");
      return switch (text(m, "kind")) {
        case "domain" -> new DomainException(DomainException.Kind.valueOf(text(m, "domainKind")), text(m, "message"));
        case "transition" -> new IllegalTransitionException(text(m, "entity"), MachineStatus.valueOf(text(m, "from")),
            MachineStatus.valueOf(text(m, "to")));
        default -> new IllegalStateException("Maschinenfehler: " + shorten(String.valueOf(m.get("type"))));
      };
    } catch (RuntimeException unreadable) {
      return new IllegalStateException("Fehlermeldung der Maschinen unlesbar");
    }
  }

  private static String text(Map<?, ?> m, String key) {
    if (m.get(key) instanceof String s && !s.isEmpty()) return s;
    throw new IllegalArgumentException("Feld " + key + " fehlt");
  }

  /** A state a machine itself can report: never UNKNOWN, that one only the gateway sets. */
  private static MachineStatus reported(Map<?, ?> m, String key) {
    String s = text(m, key);
    for (MachineStatus status : MachineStatus.values()) {
      if (status != MachineStatus.UNKNOWN && status.name().equals(s)) return status;
    }
    throw new IllegalArgumentException("unbekannter Zustand " + shorten(s));
  }

  private static int count(Map<?, ?> m, String key) {
    if (m.get(key) instanceof Long n && n >= 0 && n <= Integer.MAX_VALUE) return n.intValue();
    throw new IllegalArgumentException("Feld " + key + " ist keine Anzahl");
  }

  private static boolean flag(Map<?, ?> m, String key) {
    if (m.get(key) instanceof Boolean b) return b;
    throw new IllegalArgumentException("Feld " + key + " fehlt");
  }

  private static String shorten(String s) {
    return s.length() <= 40 ? s : s.substring(0, 40) + "…";
  }
}
```

```java
/**
 * The simulated machines as an OPC UA server (Spec 9). Anyone on this computer may read and subscribe; only the
 * gateway, signed in with a password made fresh at every start, may call methods, because a command past
 * SmartFactory would put the two out of step. Bound to 127.0.0.1 with SecurityPolicy None: the platform has no
 * login and is for local use (Spec 16); the password travels unencrypted over the loopback interface only.
 *
 * <p>Methods run under this server's own lock, never under the platform lock: the gateway waits for the answer
 * while it holds the platform lock, so taking it here would deadlock. The answers of the last calls are kept by call
 * id; a call sent again after its answer was lost runs only once.
 */
public final class MachineServer {
  public static final String NAMESPACE = "urn:nexus:machines";
  static final String GATEWAY_USER = "nexus-gateway";
  private static final Logger log = LoggerFactory.getLogger(MachineServer.class);
  private static final int KEPT_ANSWERS = 16;

  private final int port;
  private final String password = newPassword();
  private final Object lock = new Object();
  private final FeedbackOutbox outbox = new FeedbackOutbox();
  private final Map<Long, Variant[]> answers = new LinkedHashMap<>();   // oldest first, guarded by lock
  private Simulation simulation;                                       // guarded by lock
  private MachineNamespace namespace;                                  // guarded by lock
  private OpcUaServer server;
  private volatile boolean loseNextAnswer;

  public MachineServer(int port) {
    this.port = port == 0 ? freePort() : port;
  }

  public synchronized MachineServer start() {
    if (server != null) return this;
    var anonymous = new UserTokenPolicy("anonymous", UserTokenType.Anonymous, null, null, null);
    var gateway = new UserTokenPolicy("gateway", UserTokenType.UserName, null, null, SecurityPolicy.None.getUri());
    EndpointConfig endpoint = EndpointConfig.newBuilder()
        .setBindAddress("127.0.0.1").setBindPort(port).setHostname("127.0.0.1").setPath("/nexus")
        .setSecurityPolicy(SecurityPolicy.None).setSecurityMode(MessageSecurityMode.None)
        .addTokenPolicies(anonymous, gateway).build();
    OpcUaServerConfig config = OpcUaServerConfig.builder()
        .setApplicationUri("urn:nexus:machines").setProductUri("urn:nexus")
        .setApplicationName(LocalizedText.english("NEXUS Maschinen"))
        .setEndpoints(Set.of(endpoint))
        .setIdentityValidator(new CompositeValidator(AnonymousIdentityValidator.INSTANCE,
            new UsernameIdentityValidator(c -> GATEWAY_USER.equals(c.getUsername()) && password.equals(c.getPassword()))))
        .build();
    var opcUa = new OpcUaServer(config, profile -> new OpcTcpServerTransport(OpcTcpServerTransportConfig.newBuilder().build()));
    var nodes = new MachineNamespace(opcUa, this);
    nodes.startup();
    try {
      opcUa.startup().get(10, TimeUnit.SECONDS);
    } catch (InterruptedException e) {
      Thread.currentThread().interrupt();
      throw new IllegalStateException("OPC-UA-Server: Start unterbrochen", e);
    } catch (ExecutionException | TimeoutException e) {
      throw new IllegalStateException("OPC-UA-Server startet nicht auf Port " + port, e);
    }
    synchronized (lock) {
      namespace = nodes;
      if (simulation != null) namespace.publish(simulation);     // after a restart the values are there at once
    }
    server = opcUa;
    log.info("OPC-UA-Server der Maschinen unter {}", endpointUrl());
    return this;
  }

  public synchronized void stop() {
    if (server == null) return;
    try {
      server.shutdown().get(10, TimeUnit.SECONDS);
    } catch (InterruptedException e) {
      Thread.currentThread().interrupt();
    } catch (ExecutionException | TimeoutException e) {
      log.warn("OPC-UA-Server hält nicht sauber an", e);
    }
    server = null;
  }

  public String endpointUrl() {
    return "opc.tcp://127.0.0.1:" + port + "/nexus";
  }

  String gatewayPassword() {
    return password;
  }

  /** The running machines; only inside execute. */
  Simulation sim() {
    if (simulation == null) throw DomainException.conflict("Maschinen noch nicht gestartet");
    return simulation;
  }

  /** New machines; only inside execute. */
  void newMachines(long seed) {
    simulation = PlantMachines.newSimulation(seed, outbox);
  }

  /** Runs one command at most once per call id; answers [reports, error or null]. */
  Variant[] execute(long callId, Runnable command) throws UaException {
    Variant[] answer;
    synchronized (lock) {
      answer = answers.get(callId);
      if (answer == null) {
        String error = null;
        try {
          command.run();
        } catch (RuntimeException e) {
          error = MachineWire.error(e);
        }
        answer = new Variant[] {Variant.ofString(MachineWire.items(outbox.drain())), Variant.ofString(error)};
        answers.put(callId, answer);
        if (answers.size() > KEPT_ANSWERS) answers.remove(answers.keySet().iterator().next());
        if (simulation != null) namespace.publish(simulation);
      }
    }
    if (loseNextAnswer) {
      loseNextAnswer = false;
      throw new UaException(StatusCodes.Bad_Timeout);
    }
    return answer;
  }

  /** Tests only: the next call runs, but its answer is lost as if the connection broke. */
  void loseNextAnswer() {
    loseNextAnswer = true;
  }

  /** Tests only: a value as a broken device would deliver it; the next call overwrites it. */
  void override(String path, DataValue value) {
    synchronized (lock) {
      namespace.override(path, value);
    }
  }

  private static int freePort() {
    try (var socket = new ServerSocket(0, 0, InetAddress.getLoopbackAddress())) {
      return socket.getLocalPort();
    } catch (IOException e) {
      throw new UncheckedIOException(e);
    }
  }

  private static String newPassword() {
    byte[] bytes = new byte[24];
    new SecureRandom().nextBytes(bytes);
    return Base64.getUrlEncoder().withoutPadding().encodeToString(bytes);
  }
}
```

```java
        .setBrowseName(newQualifiedName(name)).setDisplayName(LocalizedText.english(name)).build();
    Argument[] inputs = new Argument[arguments.length + 1];
    inputs[0] = argument("callId", NodeIds.Int64);
    System.arraycopy(arguments, 0, inputs, 1, arguments.length);
    var handler = new AbstractMethodInvocationHandler(node) {
      @Override
      public Argument[] getInputArguments() {
        return inputs;
      }

      @Override
      public Argument[] getOutputArguments() {
        return OUTPUTS;
      }

      @Override
      protected Variant[] invoke(InvocationContext context, Variant[] in) throws UaException {
        boolean gateway = context.getSession().map(s -> s.getIdentity() instanceof Identity.UsernameIdentity u
            && MachineServer.GATEWAY_USER.equals(u.getUsername())).orElse(false);
        if (!gateway) throw new UaException(StatusCodes.Bad_UserAccessDenied);
        return owner.execute((Long) in[0].value(), command.apply(in));

  }

  }

  @Override public void onMonitoringModeChanged(List<MonitoredItem> items) { subscriptions.onMonitoringModeChanged(items); }
```

```java
import org.eclipse.milo.opcua.stack.core.types.structured.CallMethodResult;

import org.slf4j.LoggerFactory;

/**
 * MachineGateway over OPC UA (Spec 2a, 9). Every call of the plant is a method call on the machine server; the
 * reports come back as its answer and reach SmartFactory before the call returns, exactly as in memory. Values for
 * the frame are read in one request when a call has changed them.
 *
 * <p>Called only by the plant under the platform lock, one call at a time. Milo's threads only flip
 * {@link #sessionActive}; nothing here is locked on them. A call whose answer is lost is sent once more with the
 * same call id at once; if that fails too, the machines count as unreachable until the connection is back
 * (Task 6).
 */
public final class OpcUaMachines implements MachineGateway {
  private static final Logger log = LoggerFactory.getLogger(OpcUaMachines.class);
  /** No answer: the call may or may not have run on the server. */
  private static final Set<Long> NO_ANSWER = Set.of(StatusCodes.Bad_Timeout, StatusCodes.Bad_RequestTimeout,
      StatusCodes.Bad_ConnectionClosed, StatusCodes.Bad_ConnectionRejected, StatusCodes.Bad_SessionClosed,
      StatusCodes.Bad_SessionIdInvalid, StatusCodes.Bad_SecureChannelClosed, StatusCodes.Bad_NotConnected,
      StatusCodes.Bad_ServerNotConnected, StatusCodes.Bad_NoCommunication, StatusCodes.Bad_CommunicationError);
  private static final long MAX_BACKOFF_MS = 30_000;

  private record Pending(String method, Variant[] inputs) {}

  private final OpcUaClient client;
  private final MachineFeedback target;
  private final EventBus bus;
  private final List<String> machineIds = PlantMachines.machineIds();
  private final List<String> conveyorIds = PlantMachines.conveyorIds();
  private final UShort ns;
  private final NodeId plant;
  private final List<NodeId> valueNodes = new ArrayList<>();
  private final Map<String, MachineStatus> known = new TreeMap<>();
  private final Map<String, Simulation.MachineView> views = new TreeMap<>();
  private final Map<String, Simulation.ConveyorView> conveyors = new TreeMap<>();
  private final Set<String> warned = new TreeSet<>();
  private volatile boolean sessionActive = true;
  private boolean reachable = true;
  private boolean suspect;
  private boolean valuesStale = true;
  private long callId;
  private Pending pending;
  private long retryAt;
  private long backoffMs = 1_000;

  public static OpcUaMachines connect(MachineServer server, MachineFeedback target, EventBus bus) {
    try {
      OpcUaClient client = OpcUaClient.create(server.endpointUrl(),
          endpoints -> endpoints.stream()
              .filter(e -> SecurityPolicy.None.getUri().equals(e.getSecurityPolicyUri())).findFirst(),
          transport -> {},
          config -> config.setApplicationUri("urn:nexus:gateway")
              .setApplicationName(LocalizedText.english("NEXUS Maschinen-Gateway"))
              .setIdentityProvider(new UsernameProvider(MachineServer.GATEWAY_USER, server.gatewayPassword()))
              .setRequestTimeout(Unsigned.uint(2_000)));
      client.connect();
      return new OpcUaMachines(client, target, bus);
    } catch (UaException e) {
      throw new IllegalStateException("OPC-UA-Verbindung zu " + server.endpointUrl() + " fehlgeschlagen", e);
    }
  }

  private OpcUaMachines(OpcUaClient client, MachineFeedback target, EventBus bus) {
    this.client = client;
    this.target = target;
    this.bus = bus;
    this.ns = client.getNamespaceTable().getIndex(MachineServer.NAMESPACE);
    if (ns == null) throw new IllegalStateException("OPC-UA-Server ohne Namensraum " + MachineServer.NAMESPACE);
    this.plant = new NodeId(ns, "Plant");
    for (String id : machineIds) {
      known.put(id, MachineStatus.IDLE);
      for (String name : MachineNamespace.MACHINE_VALUES) valueNodes.add(new NodeId(ns, "Machines/" + id + "/" + name));
    }
    for (String id : conveyorIds) {
      for (String name : MachineNamespace.CONVEYOR_VALUES) valueNodes.add(new NodeId(ns, "Conveyors/" + id + "/" + name));
    }
    client.addSessionActivityListener(new SessionActivityListener() {
      @Override public void onSessionActive(UaSession session) { sessionActive = true; }

      @Override public void onSessionInactive(UaSession session) { sessionActive = false; }
    });
  }

  public void close() {
    try {
      client.disconnect();
    } catch (UaException e) {
      log.debug("OPC UA: Trennen nicht bestätigt", e);
    }
  }

  // ---- calls ----------------------------------------------------------------------------------------------

  private void call(String method, Variant... args) {
    if (!reachable || suspect) {
      throw DomainException.conflict("Maschinen nicht erreichbar: OPC-UA-Verbindung getrennt");
    }
    Variant[] inputs = new Variant[args.length + 1];
    inputs[0] = Variant.ofInt64(++callId);
    System.arraycopy(args, 0, inputs, 1, args.length);
    Variant[] answer = send(method, inputs);
    if (answer == null && sessionActive) answer = send(method, inputs);     // same id: runs at most once
    if (answer == null) {
      pending = new Pending(method, inputs);
      suspect = true;                    // the next step treats the machines as unreachable until it is answered
      return;
    }
    deliver(answer);
  }

  /** The answer, or null if none came (the call may or may not have run). */
  private Variant[] send(String method, Variant[] inputs) {
    try {
      CallMethodResult r = client.call(List.of(new CallMethodRequest(plant, new NodeId(ns, "Plant/" + method), inputs)))
          .getResults()[0];
      StatusCode status = r.getStatusCode();
      if (status.isGood()) return r.getOutputArguments();
      if (NO_ANSWER.contains(status.getValue())) return null;
      throw new IllegalStateException("OPC UA lehnt " + method + " ab: " + status);
    } catch (UaException noAnswer) {
      return null;
    }
  }

  /** Hands the reports of an answer on in order, then throws its error. */
  private void deliver(Variant[] answer) {
    valuesStale = true;
    String reports = answer[0].value() instanceof String s ? s : null;
    MachineWire.Parsed parsed = MachineWire.parseItems(reports, machineIds);
    for (String reason : parsed.rejected()) discard(reason);
    for (FeedbackOutbox.Item item : parsed.items()) {
      if (item instanceof FeedbackOutbox.StatusChanged s) known.put(s.machineId(), s.to());
      item.deliverTo(target);
    }
    if (answer[1].value() instanceof String error) throw MachineWire.exception(error);
  }

  private void discard(String reason) {
    log.warn("OPC UA: Meldung verworfen: {}", reason);
    bus.publish(EventTypes.DECISION, "opcua", Severity.WARNING, null,
        new Payloads.Decision("OPC UA", "verworfen", List.of(), "Meldung verworfen: " + reason));
  }

  // ---- MachineGateway ---------------------------------------------------------------------------------------

  @Override
  public void reset(long seed) {
    call("Reset", Variant.ofInt64(seed));
    for (String id : machineIds) known.put(id, MachineStatus.IDLE);
    views.clear();
    conveyors.clear();
  }

  @Override
  public void step(long dtMs) {
    call("Step", Variant.ofInt64(dtMs));
  }

  @Override
  public void setRules(SimRules r) {
    call("SetRules", Variant.ofBoolean(r.randomFaults()), Variant.ofBoolean(r.autoRepair()),
        Variant.ofBoolean(r.autoMaintenance()), Variant.ofDouble(r.maintenanceThreshold()));
  }

  @Override
  public void configure(String machineId, int overridePercent, boolean coolant) {
    call("Configure", Variant.ofString(machineId), Variant.ofInt32(overridePercent), Variant.ofBoolean(coolant));
  }

  @Override public void start(String machineId) { call("Start", Variant.ofString(machineId)); }

  @Override public void stop(String machineId) { call("Stop", Variant.ofString(machineId)); }

  @Override public void repair(String machineId) { call("Repair", Variant.ofString(machineId)); }

  @Override public void maintain(String machineId) { call("Maintain", Variant.ofString(machineId)); }

  @Override
  public void injectFault(String machineId, String faultTypeId) {
    call("InjectFault", Variant.ofString(machineId), Variant.ofString(faultTypeId));
  }

  @Override
  public void startJob(MachineJob job) {
    call("StartJob", Variant.ofString(job.machineId()), Variant.ofString(job.orderId()), Variant.ofInt32(job.stepSeq()),
        Variant.ofString(job.productId()), Variant.ofInt32(job.quantity()), Variant.ofInt64(job.setupMs()),
        Variant.ofInt64(job.processMs()));
  }

  @Override
  public List<Simulation.MachineView> views() {
    refreshIfStale();
    List<Simulation.MachineView> out = new ArrayList<>();
    for (String id : machineIds) {
      Simulation.MachineView v = views.getOrDefault(id,
          new Simulation.MachineView(id, known.get(id), null, 0, 0, 0, 0, 0, 0, 0, null));
      if (known.get(id) == MachineStatus.UNKNOWN) {
        v = new Simulation.MachineView(id, MachineStatus.UNKNOWN, v.orderId(), v.stepSeq(), v.progress(),
            v.temperature(), v.vibration(), v.power(), v.spindle(), v.wear(), v.faultLabel());
      }
      out.add(v);
    }
    return out;
  }

  @Override
  public List<Simulation.ConveyorView> conveyors() {
    refreshIfStale();
    List<Simulation.ConveyorView> out = new ArrayList<>();
    for (String id : conveyorIds) out.add(conveyors.getOrDefault(id, new Simulation.ConveyorView(id, List.of())));
    return out;
  }

  // ---- values -----------------------------------------------------------------------------------------------

  private void refreshIfStale() {
    if (!valuesStale || !reachable || suspect) return;
    try {
      readValues();
    } catch (RuntimeException unanswered) {
      suspect = true;
    }
  }

  /** Reads every machine and conveyor value in one request; bad or implausible values keep the last good ones. */
  private void readValues() {
    List<DataValue> values;
    try {
      values = client.readValues(0, TimestampsToReturn.Neither, valueNodes);
    } catch (UaException e) {
      throw new IllegalStateException("OPC UA: Werte nicht lesbar", e);
    }
    int i = 0;
    for (String id : machineIds) {
      int n = MachineNamespace.MACHINE_VALUES.size();
      Simulation.MachineView view = machineView(id, values.subList(i, i + n));
      i += n;
      keepIfValid(id, view, views);
    }
    for (String id : conveyorIds) {
      int n = MachineNamespace.CONVEYOR_VALUES.size();
      Simulation.ConveyorView view = conveyorView(id, values.subList(i, i + n));
      i += n;
      keepIfValid(id, view, conveyors);
    }
    valuesStale = false;
  }

  private <V> void keepIfValid(String id, V view, Map<String, V> into) {
    if (view != null) {
      into.put(id, view);
      warned.remove(id);
    } else if (warned.add(id)) {
      log.warn("OPC UA: ungültige Werte von {} verworfen, die letzten gültigen bleiben", id);
    }
  }

  private static Simulation.MachineView machineView(String id, List<DataValue> v) {
    for (DataValue d : v) if (!d.statusCode().isGood()) return null;
    MachineStatus status = null;
    if (v.get(0).value().value() instanceof String s) {
      for (MachineStatus candidate : MachineStatus.values()) {
        if (candidate != MachineStatus.UNKNOWN && candidate.name().equals(s)) status = candidate;
      }
    }
    Object order = v.get(1).value().value();
    Object label = v.get(9).value().value();
    if (status == null || (order != null && !(order instanceof String)) || (label != null && !(label instanceof String))
        || !(v.get(2).value().value() instanceof Integer step) || step < 0) {
      return null;
    }
    double progress = number(v.get(3), 0, 1);
    double temperature = number(v.get(4), -20, 200);
    double vibration = number(v.get(5), 0, 50);
    double power = number(v.get(6), 0, 200);
    double spindle = number(v.get(7), 0, 20_000);
    double wear = number(v.get(8), 0, 1);
    if (Double.isNaN(progress + temperature + vibration + power + spindle + wear)) return null;
    return new Simulation.MachineView(id, status, (String) order, step, progress, temperature, vibration, power,
        spindle, wear, (String) label);
  }

  /** The value if it is a number within [min, max], otherwise NaN. */
  private static double number(DataValue d, double min, double max) {
    return d.value().value() instanceof Double x && x >= min && x <= max ? x : Double.NaN;
  }

  private static Simulation.ConveyorView conveyorView(String id, List<DataValue> v) {
    for (DataValue d : v) if (!d.statusCode().isGood()) return null;
    Object[] orders = array(v.get(0));
    Object[] steps = array(v.get(1));
    Object[] positions = array(v.get(2));
    if (orders == null || steps == null || positions == null
        || orders.length != steps.length || orders.length != positions.length) {
      return null;
    }
    List<Simulation.ConveyorItem> items = new ArrayList<>();
    for (int i = 0; i < orders.length; i++) {
      if (!(orders[i] instanceof String order) || !(steps[i] instanceof Integer step)
          || !(positions[i] instanceof Double at) || !(at >= 0 && at <= 1_000)) {
        return null;
      }
      items.add(new Simulation.ConveyorItem(order, step, at));
    }
    return new Simulation.ConveyorView(id, items);
  }

  /** An array value; an empty or missing array is an empty one. */
  private static Object[] array(DataValue d) {
    Object value = d.value().value();
    if (value == null) return new Object[0];
    return value instanceof Object[] a ? a : null;
  }
}
```

```java
  /**
   * One step of the machines. While they are unreachable, nothing is called: no step waits for a timeout under the
   * platform lock. The machines stand still meanwhile; the plant's clock goes on.
   */
  @Override
  public void step(long dtMs) {
    if (reachable && (suspect || !sessionActive)) lost();
    if (!reachable && sessionActive && System.currentTimeMillis() >= retryAt) regain();
    if (reachable) call("Step", Variant.ofInt64(dtMs));
  }

  /** All machines count as UNKNOWN: SmartFactory plans around them and gives them nothing. */
  private void lost() {
    reachable = false;
    retryAt = System.currentTimeMillis() + backoffMs;
    connection(Severity.ERROR, "OPC UA getrennt, Maschinen gelten als unbekannt");
    for (String id : machineIds) {
      MachineStatus before = known.get(id);
      if (before == MachineStatus.UNKNOWN) continue;
      known.put(id, MachineStatus.UNKNOWN);
      target.statusChanged(id, before, MachineStatus.UNKNOWN);
    }
  }

  /**
   * Fetches a lost answer (same call id: the server runs the call at most once), reads the values, then reports
   * every machine still UNKNOWN in the state it really is in. If anything fails, tries again after the backoff.
   */
  private void regain() {
    Variant[] replayed = null;
    try {
      if (pending != null) {
        replayed = send(pending.method(), pending.inputs());
        if (replayed == null) throw new IllegalStateException("keine Antwort auf " + pending.method());
      }
      readValues();                       // after the replayed call ran: the values include its effect
    } catch (RuntimeException stillGone) {
      backoffMs = Math.min(backoffMs * 2, MAX_BACKOFF_MS);
      retryAt = System.currentTimeMillis() + backoffMs;
      return;
    }
    String replayedMethod = pending == null ? null : pending.method();
    pending = null;
    reachable = true;
    suspect = false;
    backoffMs = 1_000;
    connection(Severity.INFO, "OPC UA wieder verbunden");
    if (replayed != null) {
      try {
        deliver(replayed);
      } catch (RuntimeException refused) {             // its caller is long gone: report instead of throwing
        bus.publish(EventTypes.DECISION, "opcua", Severity.ERROR, null, new Payloads.Decision("OPC UA", "nachgeholt",
            List.of(), replayedMethod + " nach Verbindungsverlust abgelehnt: " + refused.getMessage()));
      }
    }
    for (String id : machineIds) {
      if (known.get(id) != MachineStatus.UNKNOWN) continue;
      MachineStatus now = views.containsKey(id) ? views.get(id).status() : MachineStatus.IDLE;
      known.put(id, now);
      target.statusChanged(id, MachineStatus.UNKNOWN, now);
    }
  }

  private void connection(Severity severity, String message) {
    if (severity == Severity.ERROR) log.warn(message);
    else log.info(message);
    bus.publish(EventTypes.OPCUA_CONNECTION, "opcua", severity, null, new Payloads.Note(message));
  }
```

Den Klassenkommentar um den Absatz ergänzen: „While unreachable, every machine is UNKNOWN (Spec 9): no calls, commands are refused with a conflict, the frame shows the last good values with status UNKNOWN. Milo reconnects the session itself; the gateway tries again after 1 s, doubling up to 30 s."

Die Simulation läuft hinter einem Milo-OPC-UA-Server auf `127.0.0.1`: je Maschine Status, Auftrag, Fortschritt und Sensoren als Variablen, je Förderband die Teile, dazu die Methoden der Anlage (`Reset`, `Step`, Regeln, Befehle, `StartJob`). - **TLS und Zertifikate für OPC UA.** Nur lokaler Betrieb (Spec 16, 19). Wer den Server über `127.0.0.1` hinaus öffnen will, braucht eine Sicherheitsrichtlinie mit Zertifikaten; das gehört zu einer Betriebsfreigabe, nicht zu M1.
- **Simulierter Verbindungsverlust im Scenario Lab.** Ein Szenario „OPC UA getrennt" kann M3 auf `MachineServer.stop()/start()` aufsetzen.
- **Zustand `UNKNOWN` in der Oberfläche.** M2 zeigt ihn an; das Zustandsbild liefert ihn schon.
